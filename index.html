📜 Règles du Mode 1v1 (Morpion Géographique) :
  • 🎯 Objectif : Aligner 3 cases de votre couleur (🟢 J1 ou 🔵 J2) pour gagner le match.

RÈGLES DU JEU

Comment jouer à CountryDoku ?

1

Mode Solo : Complétez les 9 cases de la grille avec 3 vies maximum.

2

Mode 1v1 (30s / tour) : Vous avez 30 secondes par tour. Chaque bonne réponse capture une case. Le premier qui aligne 3 cases (🟢 J1 / 🔵 J2) gagne !

3

Info-bulles (ⓘ) : Cliquez sur le symbole ⓘ à côté d'un critère pour voir son explication exacte.
